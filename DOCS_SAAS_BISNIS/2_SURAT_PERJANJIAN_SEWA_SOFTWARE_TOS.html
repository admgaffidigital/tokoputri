4.1. Perjanjian ini berlaku untuk masa sewa paket Tahunan selama 1 (Satu) Tahun Penuh sejak tanggal aktivasi.
4.2. Notifikasi tagihan perpanjangan akan diinformasikan oleh sistem secara otomatis melalui Panel Kontrol Owner mulai 7 (tujuh) hari sebelum masa aktif berakhir.
4.3. Setiap perpanjangan sewa yang dilunasi akan divalidasi oleh PIHAK PERTAMA dengan menerbitkan Kode Lisensi Kriptografis Resmi yang diinput pada menu Pengaturan Toko.

5.1. Apabila masa sewa berakhir, sistem memberikan Masa Tenggang (Grace Period) selama 7 (tujuh) hari kalender di mana sistem kasir dan toko tetap dapat beroperasi normal.
5.2. Apabila melewati masa tenggang 7 hari perpanjangan belum dilakukan, sistem akan masuk ke mode Penguncian Anggun (Graceful Lockout).
5.3. Jaminan Data Aman: Mode penguncian TIDAK MENGHAPUS DATA APAPUN. Seluruh data toko tersimpan aman di database cloud dan akan langsung aktif kembali seketika kode lisensi baru diaktifkan.
